# 1. Purpose

This document defines the official terminology used throughout the PersonaDNA platform.

All architecture documents, source code, APIs, schemas and applications shall use these definitions consistently.

---

# 2. Platform

**PersonaDNA**

The independent Cognitive Intelligence Platform responsible for understanding, modelling and preserving human cognitive identity.

---

# 3. Architecture

**PRA**

PersonaDNA Reference Architecture.

The official architecture documentation of the platform.

---

# 4. Engine

An independent software component responsible for one primary capability.

Examples:

- Identity Engine
- Meaning Engine
- WritingDNA Engine
- Memory Engine

---

# 5. Knowledge Object

The smallest managed unit of knowledge within PersonaDNA.

Examples include:

- Document
- Note
- Image
- Conversation
- Memory
- Observation
- Reflection
- Decision
- Question
- Answer

---

# 6. Persona

The continuously evolving cognitive representation of an individual.

A Persona is built from evidence rather than assumptions.

---

# 7. PersonaDNA

The structured representation of a person's cognitive identity derived from accumulated observations.

---

# 8. Identity

The collection of characteristics describing how an individual thinks, learns, communicates and evolves.

---

# 9. Observation

Raw information collected without interpretation.

Observations form the evidence base for future understanding.

---

# 10. Evidence

Verified observations supporting an inference or conclusion.

Evidence remains distinguishable from interpretation.

---

# 11. Inference

A conclusion derived from one or more pieces of evidence.

---

# 12. Memory

Persisted information retained for future retrieval.

Memory stores information.

Memory does not create understanding.

---

# 13. Knowledge

Structured understanding created from connected information.

Knowledge contains meaning and relationships.

---

# 14. Meaning

The semantic understanding extracted from information.

Meaning represents interpretation supported by evidence.

---

# 15. Relationship

A meaningful connection between two or more knowledge objects.

Relationships increase contextual understanding.

---

# 16. Intelligence Engine

Any engine that transforms information into higher-value understanding.

---

# 17. Generation

The production of new content based upon understanding.

Generation is always the final stage of the intelligence pipeline.

---

# 18. Application

Software that consumes PersonaDNA services.

Examples include:

- SIA
- Shilpkar
- SwingLab
- AptiQuiz

Applications remain independent of the PersonaDNA platform.

---

# 19. Immutable

Architecture assets that change only through formal version updates.

Examples:

- Vision
- Constitution
- Core Principles
- Architecture Laws
- Terminology

---

# 20. Evolutionary

Architecture assets expected to improve while maintaining architectural compatibility.

Examples:

- Engine Specifications
- Knowledge Models
- APIs
- Schemas

---

# 21. Operational

Executable implementation assets.

Examples:

- Source code
- Tests
- Scripts
- APIs
- SDKs
