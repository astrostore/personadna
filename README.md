## Mission

PersonaDNA is a Cognitive Intelligence Platform designed to discover,
understand, preserve and augment human cognitive identity through
modular intelligence engines.

The platform is being developed using a Reference Architecture
approach before implementation.

Documentation is organized under the PersonaDNA Reference
Architecture (PRA).
